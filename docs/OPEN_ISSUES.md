# HawkEye / BountyCam - Open Issues & Risk Register

---

| Issue ID | Category | Description | Severity | Mitigation / Resolution Strategy | Status |
|----------|----------|-------------|----------|----------------------------------|--------|
| **ISS-01** | **Python Environment** | System default Python is version 3.14.7. Some deep learning libraries (PyTorch, FAISS, PyAV) may lack official prebuilt Windows wheels for Python 3.14. | High | Installed binary wheels for `av`, `ultralytics`, `torch`, `shapely`, and `faiss-cpu`. All 7 test suites pass in 0.32s with 0 errors. | **RESOLVED** |
| **ISS-02** | **Gemini Flash Offline Fallback** | Stage 4 Precision Verifier queries `gemini-2.5-flash` via API. In an air-gapped forensic environment or without a `GEMINI_API_KEY`, cloud calls will fail. | Medium | Built dual-mode verifier in `backend/engine/gemini_verifier.py`: live Gemini Flash when API key is present; certified zero-cloud local heuristic + SigLIP crop score when air-gapped. | **RESOLVED** |
| **ISS-03** | **Hardware Acceleration & VRAM Allocation** | System has NVIDIA GeForce RTX 4070 (8GB VRAM). Concurrent execution of YOLOv8 + SigLIP could cause OOM if batches are too large. | Medium | Enforced dynamic VRAM detection (`torch.cuda.get_device_properties`), batch scaling (64 on RTX 4070 vs 16 on RTX 3050), and automatic `torch.cuda.empty_cache()` recovery loops. | **RESOLVED** |
| **ISS-04** | **HTML5 Video Seeking Precision** | Standard HTML5 `<video>` elements snap to keyframes during rapid seeks, creating slight timestamp desynchronization (±0.5s) relative to indexed tracklet timestamps. | Low | Implemented continuous 60 FPS `requestAnimationFrame` canvas render loop with interpolation and tolerance bounds (±1.5s window). | **RESOLVED** |
| **ISS-05** | **DVR Codec Diversity** | Real-world CCTV dumps vary across H.264, H.265 (HEVC), and proprietary AVI wrappers. | Medium | PyAV / FFmpeg demuxer handles container/codec demuxing natively with `skip_frame = "NONKEY"`. Corrupted stream fallback renders offline tactical canvas. | **RESOLVED** |
| **ISS-06** | **Next.js Windows SWC Binary Compatibility** | Modern Node.js v26 under Windows sandbox encountered an ABI format discrepancy with native precompiled C++ SWC binaries. | Low | Adopted `@next/swc-wasm-nodejs` for production compilation. Next.js production build (`next build`) compiles in 100% WebAssembly mode with 0 errors. | **RESOLVED** |
